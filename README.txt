LEKHANI — Pravin Bhave Author Website (app-style, English + मराठी)

QUICK START
1. Keep index.html and the assets folder together.
2. Double-click index.html to preview in a modern browser.
3. To publish, upload the whole folder contents to your hosting web root (index.html at the root).

HOW IT WORKS
- Opening page -> ENTER -> choose English or मराठी.
- App layout: Home, Books, Author, Contact tabs (bottom bar on phones, top bar on desktop).
- Language switch "मराठी | English" is always in the top bar (and inside every book sheet). Switching keeps the current tab, search text and open book. The choice is remembered on the reader's device.
- Books tab: search (works across both languages' titles and descriptions), filters (All / English / Marathi / On Kindle), tap a cover for the full description.
- Direct links: index.html#en, index.html#mr, or #en/books, #mr/about, #en/contact.
- Kindle links: edit "const KINDLE" in the page script (English and Marathi).
- All 11 books are shown in both languages; translations were prepared by Claude, please proofread before launch.
- Fonts load from Google Fonts (Cormorant Garamond, Inter, Noto Serif/Sans Devanagari); fallback fonts are included.
